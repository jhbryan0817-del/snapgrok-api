ZENAIAN WEBSITE V6.5.0 - UPLOAD NOTES

1. Complete and verify the Clerk production-domain change first.
2. Deploy API v5.7.0 with the Zenaian website origins.
3. Replace the repository website directory with this package.
4. Keep the path website/app/page.tsx, not website/website/app/page.tsx.
5. Keep the five public environment variables in .env.example.
6. Never add server-side secrets to the website service.
7. Build with Node 22.13.1 and deploy.
8. Load or publish extension v5.3.0 after the website is live.
9. Run the production tests in the root DEPLOYMENT_GUIDE.md.
