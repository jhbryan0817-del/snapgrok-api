# Consolidated requirements

- One shared user instruction.
- Two shortcuts using that same instruction.
- Full visible-tab capture.
- Manually selected visible-tab zone capture.
- Transparent selection surface without contrasting or dimmed unselected areas.
- Ignore all additional screenshot shortcuts until the result icon returns to default.
- A-E answer icons.
- F inconclusive icon.
- Red-plus system-error icon for every technical error.
- No push notification or notification permission.
- No pause, resume, on/off, or shutdown feature.
- No account, token, quota, subscription, or balance feature.
- No screenshot or answer storage logic.
- Send only the screenshot, combined instruction, and the server-required word limit.
- Remain compatible with the existing `snapgrok-api_v2` server without server changes.
