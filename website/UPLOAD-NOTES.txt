ZENAIAN WEBSITE V6.8.0 - UPLOAD NOTES

1. Replace the repository website directory with this package.
2. Keep the path website/app/page.tsx, not website/website/app/page.tsx.
3. Keep the five public environment variables in .env.example.
4. Never add server-side secrets to the website service.
5. Build with Node 22.13.1 and deploy.
6. Do not redeploy API v5.7.0 or extension v5.3.0 for this website-only release.
7. Run the post-deployment checks in DEPLOYMENT_GUIDE.md.
