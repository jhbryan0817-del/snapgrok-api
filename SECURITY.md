# Security policy

## Supported versions

Only the code currently deployed from the `main` branch receives security fixes.

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/jhbryan0817-del/snapgrok-api/security/advisories/new).
Do not open a public issue, include live customer data, or test against accounts
you do not control.

Include the affected component, reproduction steps, impact, and any suggested
mitigation. We will acknowledge a complete report within five business days and
coordinate remediation and disclosure based on severity. This policy does not
authorize denial-of-service testing, social engineering, persistence, data
exfiltration, or access beyond the minimum needed to demonstrate the issue.
