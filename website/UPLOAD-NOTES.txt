2. Keep the path website/app/page.tsx, not website/website/app/page.tsx.
3. Keep the five public environment variables in .env.example.

6. API v5.8.1 and extension v5.3.0 remain unchanged and need no redeployment.
7. Run the post-deployment checks in the repository root DEPLOYMENT_GUIDE.md.
8. The shortcut and context controls on the landing page are local-only demos.
9. Review WHOP_CHECKOUT_TERMS.md and LEGAL_REVIEW_NOTES.md before launch.
