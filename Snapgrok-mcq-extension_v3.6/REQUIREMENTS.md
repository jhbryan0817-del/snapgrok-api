# SnapGrok MCQ V3.4 requirements

1. One shared user instruction.
2. Two user-configurable Chrome shortcuts: full visible-tab capture and selected-zone capture.
3. The selector is transparent and uses only a neutral outline; the unselected page is not darkened or tinted.
4. Further screenshot commands are ignored until the result icon has displayed for five seconds and returned to default.
5. A-E represent answers, F represents inconclusive, and every technical failure uses the red-plus system-error icon.
6. No shutdown, pause, enable/disable, balance, account, token, subscription, or user-tracking functionality.
7. No push, Chrome, desktop, web, or toast notifications.
8. No screenshot-retention option or screenshot-storage logic.
9. Send only the screenshot, combined instruction, and `maxWords: 20` to the existing server.
10. No server-side code change.
