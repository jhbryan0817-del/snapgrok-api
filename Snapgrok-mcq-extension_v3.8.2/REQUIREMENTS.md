# SnapGrok V3.8 requirements

- One shared user instruction.
- Full visible-tab and selected-zone capture shortcuts.
- Ignore new shortcuts until the current result icon has returned to default.
- No notifications, pause control, account tracking, token tracking, or screenshot storage.
- Support one or several correct options from A-E.
- Single answer: lowercase answer letter icon.
- Multiple answers: check mark plus answer count; hover title lists exact options.
- Inconclusive: question-mark icon.
- System failure: exclamation-mark icon.
- Processing: processing icon.
- Result duration: four seconds.
- Existing server request shape remains unchanged.
